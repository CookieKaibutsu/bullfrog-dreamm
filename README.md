## Magic Carpet<br>
When the game starts for the first time, you will be prompted to select the sound and music sources as well as the language.<br>
Choose SoundBlaster 16 for the Sound Source and then the Music Source you chose in DREAMM before starting.<br>
The settings for the SoundBlaster 16 are: Sound IO: 220, IRQ: 7, DMA: 1. For MIDI music, the Music IO is 330.<br>
When loading the game thereafter, you will be given the option to change the sound settings or to progress without making a change.<br>
Press R in-game to enable high-resolution mode as the CPU Speed setting has been optimized for it.<br>
